# Steam Recommender — сохранение исключений из «Your Playtime»

Tampermonkey-скрипт для страницы
<https://store.steampowered.com/recommender/>.

## Что делает

На странице интерактивного рекомендера есть левая колонка **Your Playtime**
(«Ваше игровое время»). У каждой игры есть переключатель **Exclude / Include**.
Steam хранит эти переключения только в памяти страницы: после перезагрузки они
сбрасываются, и рекомендер снова учитывает все игры.

Скрипт запоминает выбор в `localStorage` браузера и применяет его заново при
каждой загрузке страницы. Дополнительно он подмешивает сохранённые игры в
запрос рекомендаций, поэтому они не влияют на выдачу уже с первой загрузки.

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте панель Tampermonkey → **Create a new script**.
3. Удалите шаблон и вставьте содержимое
   [`steam-recommender-persist.user.js`](./steam-recommender-persist.user.js).
4. Нажмите **Ctrl+S** (или **File → Save**).
5. Откройте <https://store.steampowered.com/recommender/> и обновите страницу.

## Как пользоваться

- Нажимайте **Exclude** у игр, которые не должны влиять на рекомендации.
- В левом нижнем углу появится плашка **«Исключено игр: N»**.
- После перезагрузки страницы исключённые игры останутся серыми, а рекомендер
  не будет их учитывать.
- **Сброс**: нажмите «сброс» на плашке дважды (второй раз — в течение 3 секунд).
  Это удалит только то, что сохранил скрипт. Игры, исключённые в настройках
  самого Steam, останутся исключёнными.

## Где хранятся данные

Ключ в `localStorage` сайта `store.steampowered.com`:

```
steamrec.excluded.v1.<steamid>
```

Значение — JSON-объект вида `{ "12345": true, "67890": false }`, где `true` —
игра исключена, `false` — явно включена (даже если Steam считает её
исключённой по умолчанию). Данные привязаны к аккаунту Steam и не передаются
на серверы Valve.

## Как это работает внутри

Страница рекомендера — отдельное React-приложение
(`applications/interactive_recommender`). Оно делает два ключевых запроса:

- `GET /recommender/<steamid>/inputs` — список игр с полями
  `{ a: appid, t: название, p: часы, l: последний запуск, i: ignored, ip: ignoredPending }`;
- `GET /recommender/<steamid>/results?...&ignored=1,2,3` — рекомендации; список
  `ignored` собирается из `inputs`.

Скрипт:

1. Перехватывает ответ `/inputs` и до того, как приложение его прочитает,
   выставляет `i`/`ip` для сохранённых игр.
2. Переписывает URL запроса `/results`, добавляя сохранённые appid в `ignored`
   (первый запрос рекомендаций уходит раньше, чем приходит `/inputs`).
3. Если ответ уже закэширован или Steam изменил формат запроса, скрипт
   «докликивает» настоящие переключатели Exclude/Include после отрисовки списка.
4. Слушает реальные клики по переключателям и сохраняет новое состояние.

## Ограничения

- Это локальное решение: выбор сохраняется в текущем браузере, а не в
  аккаунте Steam. В другом браузере или после очистки данных сайта его нужно
  сделать заново.
- Скрипт рассчитан на текущую вёрстку и запросы страницы (2026). Если Valve
  поменяет классы или API, может потребоваться обновление селекторов.
- Скрипт не трогает ползунки, теги и другие настройки рекомендера — только
  исключения из списка игр.
